# Mickeys.exe — Ball Possession Prediction

## Summary

This submission produces one possession label for each frame of the BAR-ATH tactical recording.
It uses an interpretable, weakly supervised heuristic over the supplied automatic tracking and
Smart Tagging. It is not a trained classifier. The private full-match labels are unavailable, so
no full-match accuracy or ranking score is claimed.

## Data and assets

| Asset | Use |
|---|---|
| Tactical ATD metadata (`BAR-ATH_tactical_atd.xml`) | Maps tracking slots to the two teams. Slot identities are not treated as persistent player identities. |
| Tactical ATD raw tracking (`BAR-ATH_tactical_atd.txt`) | Ball and player positions for each tactical video frame. Coordinates are normalized and converted to pitch metres for distance checks. |
| Tactical Smart Tagging (`BAR-ATH_tactical_smart_tagging.xml`) | Weak phase/team hints and set-piece intervals. Tags are automatic annotations, not ground truth. |
| Tactical or broadcast video, broadcast tracking, homography | Not used by this submission. |

The script uses the tactical frame timeline and writes exactly 199,319 rows, indexed from video
frame 0 through 199,318. The match data is gated and is not included in the repository. Obtain it
through the official participant process described in [DATA.md](DATA.md); do not commit or
redistribute it.

## Method

For each frame with a tracked ball, the system finds the closest visible player from each team. A
direct team observation is accepted only when the closest player is within 3.5 metres and is at
least 0.5 metres closer than the opposing team's closest player. This avoids assigning possession
when the ball is distant from both teams or the proximity evidence is ambiguous.

A state machine initializes from a clear direct observation and holds the current owner through
ambiguous frames and missing-ball spans. It requires 15 direct observations to switch teams, while
short evidence gaps are tolerated. Automatic attacking and defending phase tags can provide a
weaker owner hint; phase-only evidence requires 50 frames before it can change ownership. A
continuous two-second span with fewer than eight tracked players clears the remembered owner, so a
long tracking outage such as halftime does not carry the previous state into the next period.

The output labels follow the challenge definitions:

- `H` / `A`: home / away possession while play is live.
- `D`: a tracked ball more than 0.01 normalized units beyond the pitch bounds, or the pre-launch
  portion of a tagged restart when a tracked launch is detected. A launch is detected by more than
  1.5 metres of ball displacement over seven frames.
- `X`: no established owner or very sparse player tracking. Missing ball tracking alone does not
  imply a dead ball.

Known-team set-piece tags add a short restart hint. `N/A` team tags are not treated as a team
assignment. Tagging is evidence only: phase intervals are not copied as possession labels.

For loose balls and challenges, a brief nearest-player change is not immediately treated as a
turnover: the previous owner is held until the direct or phase evidence thresholds are met. There
is no separate duel or tackle classifier. At restarts, the system marks only the tagged
pre-launch interval as `D` when it detects the ball launch; it does not label the full Smart
Tagging phase as dead ball. A tagged restarting team provides a short hint only when the team is
known.

The script also writes a separate denoised Smart Tagging XML as a diagnostic side output. It
preserves the source events and removes only strongly contradicted team tags; it is not used to
produce the submitted CSV and is not a ground-truth correction.

## Training data and rule compliance

No model training was performed, and no external human-labelled match data was used. No frames
from BAR-ATH were manually labelled or corrected. All CSV labels are generated by the algorithm
from the automatic tracking and tagging.

The public five-minute ground-truth sample was not used for training or parameter selection. An
earlier implementation was run against it as a pipeline diagnostic only; the current revision is
reported as format-validated, not accuracy-validated. The private full-match ground truth and any
human-produced data about BAR-ATH were not used.

## Validation and results

The current candidate passes `evaluation/validate_submission.py`: 199,319 ordered rows, frames
0–199,318, and labels limited to `H`, `A`, `D`, and `X`. The synthetic state tests pass (10 tests).
The output contains H=92,775, A=66,277, D=12,782, and X=27,485 labels. On the tested Windows
environment (Python 3.10.6 with NumPy 1.23.5 and pandas 1.5.3), candidate generation took about
15 seconds.

These checks establish reproducibility and file validity, not label accuracy. There is no verified
full-match score for this candidate.

## Limitations

- The automatic ball track is missing on many frames, and player slots can switch identity.
- Nearest-player distance is only a proxy for controlled possession; it can confuse deflections,
  loose balls, and contested touches.
- Smart Tagging is automatic, sometimes has no team tag, and describes phases rather than exact
  possession boundaries.
- Out-of-pitch and tagged-restart cues do not identify every stoppage.
- The long-gap reset and confirmation thresholds are heuristic choices; without independent
  permitted labels or the private ground truth, their effect on full-match accuracy is unknown.
- No independent-match validation was performed.

## Reproduction

Use Python 3.8 or newer and install the pinned direct dependencies:

```bash
python -m pip install -r requirements.txt
python starter/possession.py
python -m unittest starter.test_possession
python evaluation/validate_submission.py evaluation/results/Mickeys.exe.csv
```

At minimum, place the tactical ATD metadata, raw tracking, and Smart Tagging XML in `data/tactical/`
or point `MTAH_DATA_DIR` to their parent directory. The CSV and derived XML are ignored by Git so
restricted match data and generated labels are not included in the public code repository.
